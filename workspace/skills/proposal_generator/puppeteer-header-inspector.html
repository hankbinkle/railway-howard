Header Template Styling Details:
  • Logo: height 60px, auto width (embedded as base64 or text "ZINN")
  • Address: font-size 9px, weight 300, color #4e5757
  • Address positioning: absolute, right-aligned 72px from edge
  • Rule line: 1.5px solid black, separates header from content
  • Font family: Avenir Next (with fallbacks: Avenir, Helvetica Neue, Helvetica, Arial)
  • Letter-spacing: 0.4px on address text
How to Inspect in Dev Tools:
  1. Right-click on the header area → Inspect Element
  2. Check the #hdr-content div padding and layout
  3. Inspect the .hdr-address for positioning, font-size, and color
  4. View the #hdr-rule border styling
  5. Try editing CSS in Dev Tools to experiment with changes
  6. Check Computed styles to see what Spartan font properties are actually applied
